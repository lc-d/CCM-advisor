Cartella per le note sulle conversazioni avute per ogni ticker, funzionali alla generazione del report. Es. `.note/<TICKER>/note-<YYYYMMDD>.md`.

**Un file per sessione di lavoro**, datato con il giorno della conversazione: le note non si accumulano in un unico documento ma si aggiungono come nuovi file nella stessa cartella del ticker. Ogni file apre con un indice delle sessioni del ticker e rimanda al precedente e al successivo.

Convenzione: **lo stato corrente della fase 1 — buchi ancora aperti, prossimi passi, tesi — sta sempre nel file più recente**; i file precedenti restano fotografie di quella sessione e non vanno riscritti a posteriori (al massimo si annota fra parentesi che un punto è stato risolto altrove, con il rimando).
